## Flagship Project — PAKGOV-RAG

A bilingual Urdu-English Retrieval-Augmented Generation system designed for Pakistani government document infrastructure — tax circulars (FBR), education policy (HEC), identity procedures (NADRA), corporate filings (SECP), and court judgments (Supreme Court).

**Planned architecture:**
- Hybrid retrieval — dense embeddings (mE5/LaBSE) + sparse BM25, indexed with FAISS
- Bilingual generation — QLoRA fine-tuned LLaMA-3 / mT5
- Evaluation — RAGAS framework (faithfulness, answer relevance, context precision/recall)

**Status:** In architecture/design phase — build starts alongside coursework in Year 1–2.
